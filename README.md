# sokol-tools-bin
Binaries and fips integration for https://github.com/floooh/sokol-tools

### CMake

For CMake usage, see the [CMake how-to](cmake-howto.md).

### Zig

See [build.zig](build.zig) for details!

### Fibs

Fibs integration is implemented in [fibs-extras/sokolshdc.ts](https://github.com/floooh/fibs-extras/blob/main/sokolshdc.ts).

### Fips

Fips integration lives in the `fips-files` subdirectory, but note that this
is deprecated.
